# Klasifikasi Risiko Kelulusan Mahasiswa dengan Machine Learning

## Studi kasus
Studi kasus: model klasifikasi sederhana mempelajari data sintetis untuk mengelompokkan mahasiswa menjadi 'Perlu Dukungan' atau 'On Track' berdasarkan kehadiran dan nilai tugas. Bukan untuk keputusan nyata tentang mahasiswa.

## Implementasi
Kode pada proyek ini menunjukkan penerapan konsep materi dalam skala mini. Data contoh disediakan di folder `data/`.

## Cara menjalankan
```bash
pip install -r requirements.txt
python main.py
```

## Interpretasi dan batasan
Gunakan hasil sebagai demonstrasi alur kerja. Untuk penerapan nyata, gunakan data yang dapat dipertanggungjawabkan, lakukan validasi, dan dokumentasikan asumsi serta keterbatasan.
